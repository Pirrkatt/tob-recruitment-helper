# ToB Recruitment Helper

A RuneLite plugin that helps you find Theatre of Blood teammates by highlighting applicants in chat and inspecting their gear.

## Features

- Highlights applicant names when they send messages in chat
- Inspect applicants gear and recent chat messages in the side panel
- Shows colored role tags (Nfrz, Sfrz, Mdps, Rdps) based on what applicants mention in chat
- Displays weapon icons (Scythe/SRA) next to applicants' name when they indicate they have them

## Installation

Install through the RuneLite Plugin Hub.
